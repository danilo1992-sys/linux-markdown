## Descripción

`wc` (word count) cuenta el número de líneas, palabras y caracteres de un archivo o de la entrada estándar.

## Sintaxis

```bash
wc [opciones] archivo
```

## Ejemplos de uso

Contar todo:

```bash
wc archivo.txt
```

Contar solo líneas:

```bash
wc -l archivo.txt
```

Contar solo palabras:

```bash
wc -w archivo.txt
```

Contar solo caracteres:

```bash
wc -c archivo.txt
```
