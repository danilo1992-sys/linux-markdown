## Descripción

`cd` (change directory) cambia el directorio de trabajo actual en la terminal.

## Sintaxis

```bash
cd [directorio]
```

## Ejemplos de uso

Ir al directorio home:

```bash
cd
```

Ir a un directorio específico:

```bash
cd /var/log
```

Subir un nivel:

```bash
cd ..
```

Volver al directorio anterior:

```bash
cd -
```

Ir a la raíz del sistema:

```bash
cd /
```
