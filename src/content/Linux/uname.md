## Descripción

`uname` muestra información sobre el sistema operativo y el kernel.

## Sintaxis

```bash
uname [opciones]
```

## Ejemplos de uso

Mostrar todo:

```bash
uname -a
```

Mostrar nombre del kernel:

```bash
uname -s
```

Mostrar versión:

```bash
uname -r
```

Mostrar máquina:

```bash
uname -m
```
