## Descripción

`mkdir` (make directory) crea uno o más directorios nuevos.

## Sintaxis

```bash
mkdir [opciones] directorio
```

## Ejemplos de uso

Crear un directorio:

```bash
mkdir misarchivos
```

Crear directorios anidados:

```bash
mkdir -p carpeta/subcarpeta/nivel3
```

Crear con permisos específicos:

```bash
mkdir -m 755 directorio
```

Crear varios directorios a la vez:

```bash
mkdir dir1 dir2 dir3
```
