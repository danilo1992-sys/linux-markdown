## Descripción

`sort` ordena las líneas de un archivo de texto.


## Ejemplos de uso

Ordenar alfabéticamente:

```bash
sort archivo.txt
```

Ordenar numéricamente:

```bash
sort -n archivo.txt
```

Ordenar en orden inverso:

```bash
sort -r archivo.txt
```

Ordenar ignorando mayúsculas:

```bash
sort -f archivo.txt
```

Eliminar duplicados al ordenar:

```bash
sort -u archivo.txt
```
