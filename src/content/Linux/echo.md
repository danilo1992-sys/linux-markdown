## Descripción

`echo` muestra una línea de texto o el valor de una variable en la salida estándar.


## Ejemplos de uso

Mostrar texto:

```bash
echo "Hola mundo"
```

Mostrar variable:

```bash
echo $HOME
```

Agregar texto a un archivo:

```bash
echo "nueva línea" >> archivo.txt
```

Sin salto de línea:

```bash
echo -n "texto"
```
