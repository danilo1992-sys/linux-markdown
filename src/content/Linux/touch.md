## Descripción

`touch` crea archivos vacíos o actualiza la fecha de acceso y modificación de un archivo existente.


## Ejemplos de uso

Crear archivo vacío:

```bash
 touch nuevo_archivo.txt
```

Actualizar fecha de un archivo existente:

```bash
 touch archivo_existente.txt
```

Crear varios archivos a la vez:

```bash
 touch archivo1.txt archivo2.txt archivo3.txt
```

Crear archivo con contenido:

```bash
 echo "contenido" > archivo.txt
```
