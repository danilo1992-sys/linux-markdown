---
name: "pwd"
description: "Muestra el directorio de trabajo actual."
---


## Descripción

`pwd` (print working directory) imprime la ruta completa del directorio de trabajo actual.

## Sintaxis

```bash
pwd
```

## Ejemplos de uso

Mostrar directorio actual:

```bash
pwd
```

Resultado típico:

```
/home/usuario/proyectos
```
