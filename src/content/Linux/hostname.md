## Descripción

`hostname` muestra o establece el nombre del host del sistema.


## Ejemplos de uso

Mostrar el nombre del host:

```bash
hostname
```

Mostrar la dirección IP:

```bash
hostname -I
```

Mostrar el FQDN:

```bash
hostname -f
```

Mostrar solo el nombre de dominio:

```bash
hostname -d
```
