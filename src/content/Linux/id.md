## Descripción

`id` muestra el ID de usuario, ID de grupo y grupos del usuario actual o especificado.


## Ejemplos de uso

Mostrar información del usuario actual:

```bash
id
```

Mostrar información de otro usuario:

```bash
id juan
```

Mostrar solo el ID de usuario:

```bash
id -u
```

Mostrar solo el ID de grupo:

```bash
id -g
```
